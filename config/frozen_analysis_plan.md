### S3 已撤下的偏离记录（第三轮审查要求）

原 S3 想比较"树集子池 − 线性子池"的家族效应，但实际实现中两侧**不同规模、不同任务集**：
`linear_only` = 全部非树候选（**含参照 Lasso**），`tree_only` = 全部树候选。
两者不是对称对照，**不能用 `linear_only − tree_only` 解释家族效应**。
本版**明确撤下 S3 主张**并记录该偏离，不再补一个庞大的家族机制模块。
（同时统一了口径：`linear_only` 的定义现在**在脚本与 R 包中一致**，均为"含参照"。）

## 4. 指标定义（术语冻结）

- `Cv`：验证集 C-index（**直接评价**：`concordance(Surv ~ s, reverse=TRUE, timewt="n")`）
- `Ct`：独立测试集 C-index（同一函数，**不在测试集上重新拟合、不做方向学习**）
- `Gv = Cv(规则) − Cv(参照)` 验证增益
- `Gt = Ct(规则) − Ct(参照)` 独立测试增益
- `Orel = Gv − Gt` **参照校正的选择乐观度**（不称"纯选择偏倚"）
- `Oraw = Cv(规则) − Ct(规则)` 原始落差（**另一指标，不与 Orel 混称**）
- 主比例 = **汇总 Orel / 汇总 Gv**（不用逐签名或逐队列比例的平均）

## 5. 汇总方式

先按（队列 × 划分）内部对基因集求配对平均 → 再对 5 个划分求平均 →
再对 8 个队列**等权**汇总。主表同时给出跨划分范围。
